# バックフィル(過去分の一括収集)手順

初回や新ソース追加時に、過去3年分を取り込む。通常の週次タスク(`weekly-run.md`)と同じ手順で、収集期間だけ変える。

1. 対象ソースを1〜2個に絞る(1回の処理量を抑えるため): `python pipeline/collect.py --only <source_id> --since 2023-01-01 --limit 40`
2. `weekly-run.md` の手順3以降(判定→記事作成→validate→PR)を実行する。PRタイトルは `backfill: <source_id> (<期間>)`。
3. `truncated` が0になるまで、同じコマンドを繰り返す(採用/不採用はどちらも既知URLになるため、前回の続きから進む)。
4. 新ソースは最初の1PRで品質を人が確認し、タグ・要約の傾向が良ければ残りを進める。

注意: 学会ソースは `max_items` が上限になる。年別に `since` を区切って複数回実行すること。
